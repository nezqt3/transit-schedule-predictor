# Inference

Загрузка версионированных артефактов и единая функция предсказания для FastAPI-сервиса.
По умолчанию `MODEL_NAME=baseline`: сервис запускается без артефактов и
возвращает известный baseline `prediction = cur_dev_s`. Для боевой модели
укажите `MODEL_NAME=lightgbm_plan` или `MODEL_NAME=catboost` и положите
соответствующие артефакты в `ml/artifacts/`. Если выбранный артефакт
отсутствует, сервис завершится с явной ошибкой.
