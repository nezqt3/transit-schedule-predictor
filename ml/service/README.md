# ML inference service

FastAPI предоставляет `GET /health` и `POST /predict`. По умолчанию загружается
выбранная модель `lightgbm_plan` с версией из `artifacts/release_manifest.json`.
При запуске проверяются SHA-256 весов, метаданных, калибровки риска и
планового расписания. Отсутствующий или изменённый файл останавливает загрузку.

`prediction` — регрессионный прогноз `target_delay_s` в секундах. `p_late` —
отдельно калиброванная вероятность события `target_delay_s >= 120`; у моделей
без калибровки поле равно `null`. `MODEL_NAME=baseline` выбирается только явно.

Сервис использует те же `src.features_simple` и `src.plan_features`, что и
офлайн-скрипт. Проверка паритета на test-наборе из корня репозитория:
`python scripts/verify_model_parity.py`.

Compose запускает четыре независимых CPU-процесса Uvicorn через `ML_WORKERS`;
каждый проверяет и загружает тот же релизный манифест. Для типовой равномерной
нагрузки это не меняет прогноз; при одновременном залпе 100 терминалов
уменьшает конкуренцию Python-потоков. На измеренной машине четыре процесса ML
занимали около 721 МиБ памяти суммарно.
