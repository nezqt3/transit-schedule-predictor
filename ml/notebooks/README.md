# Notebooks

- `01_eda.ipynb` — первичный анализ данных и проверка качества.
- `02_catboost.ipynb` — baseline на табличных признаках.
- `03_pytorch.ipynb` — эксперименты с нейросетевой моделью.

Ноутбуки предназначены для Kaggle и локального Jupyter. Основная логика после стабилизации экспериментов переносится в `src/`, чтобы обучение можно было воспроизвести скриптами.
