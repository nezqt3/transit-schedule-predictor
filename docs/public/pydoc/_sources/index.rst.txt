Transport Delay Predictor
=========================

Backend принимает NDTP-телеметрию, вызывает ML Service и отдаёт
защищённое REST API диспетчерской. Интерактивный OpenAPI доступен
в ``/docs``, ReDoc — в ``/redoc``.

Эта документация и статичная схема API закоммичены в репозиторий:
``docs/public/pydoc/index.html`` и ``docs/public/api.html`` открываются
локально из clone, без запущенных сервисов. Пересборка — ``make docs``.
