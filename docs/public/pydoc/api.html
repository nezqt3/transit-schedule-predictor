NDTP Parser

Бинарный парсер протокола NDTP.

Каждый кадр NDTP: [NPL 15 байт][NPH 10 байт][тело]. Все поля little-endian. Здесь живёт ВСЁ знание о протоколе: наружу модуль отдаёт только normalized-объекты из app.ndtp.schemas.
